# RXP — Undead Mage Custom Route 1–12

Отдельный модуль с пользовательским маршрутом прокачки **маг-нежить, Орда, уровни 1–12** для WoW Forever. Модуль использует встроенный парсер гайдов RestedXP; отдельное окно или собственный движок не создаются.

## Что добавлено

- Два связанных сегмента маршрута: `Mage Custom 1-6 Tirisfal Glades` и `Mage Custom 5-12 Tirisfal Glades`.
- Русские инструкции внутри шагов; команды RXP, имена NPC, названия заданий и идентификаторы предметов сохранены из исходника.
- Переход из первого сегмента во второй через `#next`; второй сегмент передаёт управление стандартному гайду RXP `12-14 Silverpine Forest`.
- Отдельный аддон, который зависит от `RXPGuides`. Основные файлы RestedXP менять не требуется.

## Установка

1. Установи и проверь, что RestedXP запускается в клиенте WoW Forever.
2. Закрой игру.
3. Создай папку `RXP_UndeadMageCustom` внутри `Interface/AddOns/` того клиента, через который запускается WoW Forever.
4. Скопируй в неё файлы `RXP_UndeadMageCustom.toc` и `UndeadMageCustom.lua` из корня этого репозитория. Папка аддона и имя TOC должны совпадать по имени: `RXP_UndeadMageCustom`.
5. Запусти игру. На экране выбора персонажа открой список аддонов и включи **RXP - Undead Mage Custom Route 1-12**, если он отключён.
6. В RestedXP найди группу **RestedXP Forever Guide (H)** и подраздел **Mage Custom Route 1-12**. Выбери `1-6 Tirisfal Glades (Mage Custom)` для начала маршрута.

Файлы `README.md` и `tests/` в папку игрового аддона копировать не нужно. Зависимость `RXPGuides` предполагает, что основной аддон RestedXP установлен под стандартным именем папки `RXPGuides`.

## Совместимость и проверка

- В TOC указан интерфейс `16001`, который присутствует среди версий интерфейса в опубликованном [TOC RestedXP](https://github.com/RestedXP/RXPGuides/blob/main/RXPGuides.toc).
- Исходник использует `RXPGuides.RegisterGuide` и директиву `#forever`. Публичный [GuideLoader.lua](https://github.com/RestedXP/RXPGuides/blob/main/GuideLoader.lua) назначает `RXPGuides.RegisterGuide` на функцию регистрации гайда, а [GuideList-forever.xml](https://github.com/RestedXP/RXPGuides/blob/main/Guides/GuideList-forever.xml) использует директиву загрузки гайдов для режима Forever. Это подтверждает выбранный способ интеграции на уровне исходников, но не доказывает успешную загрузку в конкретном клиенте.
- **Живая проверка в клиенте WoW Forever ещё не выполнена.** Структурная проверка не гарантирует, что каждый квест, NPC, координата или команда маршрута сработают на сервере.
- В исходнике есть серверно-зависимые задания и предметы. Если конкретный мир Forever отличается по доступности заданий, соответствующие шаги могут требовать корректировки.

## Структурная проверка

Из корня репозитория запусти:

```bash
python tests/validate_route.py
```

Проверка подтверждает целостность двух блоков гайда, уникальность имён и ожидаемые переходы. Это не замена проверке внутри игры.

## Исходный материал

Маршрут основан на проектном файле `Horde-01-12_Undead_Mage_Custom_Updated_v10.lua`. Содержимое шагов сохранено; добавлены только комментарии заголовка для обозначения назначения и статуса проверки.
