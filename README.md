# rxp

## Назначение

Исходное описание проекта — `rxp guide`. Репозиторий предназначен для размещения гайда; его точное назначение и область применения **требуют подтверждения**.

Эта версия README задаёт структуру документации. Она не подтверждает наличие реализованного маршрута.
