# RXP — Undead Mage Custom Route 1–12

Отдельный модуль с пользовательским маршрутом прокачки **маг-нежить, Орда, уровни 1–12** для WoW Forever. Модуль использует встроенный парсер гайдов RestedXP; отдельное окно или собственный движок не создаются.

## Что добавлено

- Два связанных сегмента маршрута: `Mage Custom 1-6 Tirisfal Glades` и `Mage Custom 5-12 Tirisfal Glades`.
- Русские инструкции внутри шагов, при этом команды RXP, имена NPC, названия заданий и идентификаторы предметов сохранены из исходника.
- Переход из первого сегмента во второй через `#next`; второй сегмент передаёт управление стандартному гайду RXP `12-14 Silverpine Forest`.
- Загрузка через отдельный аддон с зависимостью от `RXPGuides`, поэтому файлы самого RXP изменять не требуется.

## Установка

1. Установи и проверь, что RestedXP запускается в клиенте WoW Forever.
2. Закрой игру.
3. Скопируй папку `RXP_UndeadMageCustom` целиком в папку `Interface/AddOns/` именно того клиента, через который запускается WoW Forever. Внутри папки должны лежать `RXP_UndeadMageCustom.toc` и `UndeadMageCustom.lua`.
4. Запусти игру. На экране выбора персонажа открой список аддонов и включи **RXP - Undead Mage Custom Route 1-12**, если он отключён.
5. В RestedXP найди группу **RestedXP Forever Guide (H)** и подраздел **Mage Custom Route 1-12**. Выбери `1-6 Tirisfal Glades (Mage Custom)` для начала маршрута.

Не переименовывай основной аддон RestedXP без необходимости: файл модуля объявляет зависимость `RXPGuides`, чтобы API гайдов был доступен до регистрации маршрута.

## Совместимость и проверка

- В TOC указан интерфейс `16001`, который присутствует среди версий интерфейса в опубликованном TOC RestedXP, доступном на момент подготовки этого модуля.
- Исходник использует `RXPGuides.RegisterGuide` и директиву `#forever`; аналогичный способ регистрации и директива встречаются в исходниках RestedXP для Forever.
- **Живая проверка в клиенте WoW Forever ещё не выполнена.** Поэтому этот коммит подтверждает интеграцию исходника в отдельный модуль и структурные проверки, но не гарантирует, что каждый квест, NPC, координата или команда маршрута сработают на сервере без тестирования в игре.
- В исходнике есть серверно-зависимые задания и предметы. Если конкретный мир Forever отличается по доступности заданий, соответствующие шаги могут требовать корректировки.

## Структурная проверка

Из корня репозитория запусти:

```bash
python tests/validate_route.py
```

Проверка подтверждает целостность двух блоков гайда, уникальность их имён и ожидаемые переходы. Это не замена проверке внутри игры.

## Исходный материал

Маршрут основан на проектном файле `Horde-01-12_Undead_Mage_Custom_Updated_v10.lua`. Содержимое шагов сохранено; добавлены только комментарии заголовка для обозначения назначения и статуса проверки.
